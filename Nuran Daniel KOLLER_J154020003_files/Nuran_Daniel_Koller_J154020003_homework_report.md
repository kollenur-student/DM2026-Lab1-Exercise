# Reddit Stock Sentiment Analysis Report

The Reddit dataset was loaded from `newdataset/Reddit-stock-sentiment.csv` using the `text` and `label` columns. Result `load_dataset_1` reports 847 documents across the three sentiment classes. The inspection result `inspect_data_2` showed representative negative, neutral, and positive posts. No missing text values were found in `check_missing_3`, while `check_duplicates_4` identified 23 duplicate documents.

Document-length analysis in `describe_data_5` showed that most posts were short but that all sentiment classes contained long outliers. The category box plot was saved as `../plots/Nuran_Daniel_Koller_homework_plot_describe_data_5.png`. After repeated 50% sampling, the working dataset contained 212 documents in `sample_data_7`. The document-term matrix in `build_dtm_8` contained 1,777 terms and was 98.92% sparse. The term-frequency result `term_frequency_9` showed common words such as “the”, “to”, “and”, “is”, and “market”; its bar chart was saved as `../plots/Nuran_Daniel_Koller_homework_plot_turn72.png`.

The DTM heatmap result `dtm_heatmap_10` displayed a 20-document by 20-term slice with only a few non-zero entries, illustrating the sparsity of the matrix. Variance filtering with result `variance_filter_11` reduced the vocabulary from 1,777 to 399 terms. However, the Pearson filter `pearson_filter_12` used a threshold of 0.0 and therefore retained all 1,777 terms. The feature-correlation result `feature_correlation_matrix_13` showed positive relationships among common terms, including correlations between “to” and “in” and between “of” and “with”; the heatmap was saved as `../plots/Nuran_Daniel_Koller_homework_plot_feature_correlation_matrix_13.png`.

Frequent-pattern mining was run for the positive sentiment class in result `mine_patterns_14`, producing 27 patterns with minimum support 2, including terms such as “money”, “buy”, “market”, and “high”. PCA in `reduce_dimensions_15` projected the documents into two dimensions, explaining 24.08% and 7.72% of the variance in the first two components; the plot was saved as `../plots/Nuran_Daniel_Koller_homework_plot_reduce_dimensions_15.png`. The label mapping in `binarize_labels_16` encoded `-1.0`, `0.0`, and `1.0` as the three one-hot columns, while `cosine_similarity_17` gave a similarity score of 0.0754 for documents 0 and 1.
